# Excel・CSV整理サービス

Excel・CSV整理サービスを紹介する日本語の静的Webサイトです。

公開サイト: https://excel-csv-seiri-jp.sega50642.chatgpt.site/

## 内容

- 提供範囲・料金案・相談導線
- 整理前後の見本
- 広告CSVの架空データとExcel納品見本
- レスポンシブ表示

## 実行方法

`dist/index.html` をブラウザーで開いてください。ビルドやAPIキーは不要です。

## ファイル

- `dist/index.html`: ページ本文
- `dist/styles.css`: スタイル
- `dist/script.js`: 表示・メール相談リンク
- `dist/config.js`: サービス名・公開問い合わせ先・受付状態
- `dist/samples/advertising/`: 架空CSV、Excel、ZIP見本

## 現在の範囲

匿名化サンプルによる事前相談の状態です。このサイトにCSV処理の実行機能やファイル送信機能はありません。見本は架空データで、顧客実績ではありません。広告運用や効果分析は提供範囲に含みません。

この提出用リポジトリは既存サイトのソースをまとめたものです。Claude APIは使用していません。
